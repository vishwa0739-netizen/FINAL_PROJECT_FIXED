NGH FOODS - REAL WEBSITE STYLE DA-2
----------------------------------------
This version improves the first prototype with:
- Working Home / Menu / Restaurants / Orders / Contact navigation
- Restaurant section with multiple restaurant cards
- Food sections: Fast Food, Meals, Biryani, Snacks, Drinks, Desserts
- Real food/restaurant photo URLs
- Search
- Category filter
- Price/rating sorting
- Cart
- Checkout customer details
- Loading animation
- MySQL schema prepared for customers, restaurants, categories, foods, orders, order items, payments and bills

RUN:
1. Keep this folder in Downloads for now.
2. Open index.html to preview the frontend.
3. For PHP/MySQL, install/start a PHP + MySQL server on Mac.
4. Import database/ngh_foods.sql into MySQL.
5. Next development stage: connect checkout to backend/place_order.php and add customer CRUD + dashboard + reports.
